# VPN_BEST

Независимая копия каталога конфигураций для Happ. Для использования не требуется
запускать Python или держать компьютер включённым.

## Подключение на iPhone

Скопируйте ссылку целиком, откройте Happ → «+» → импорт из буфера обмена:

```text
https://raw.githubusercontent.com/dfantomasd/VPN_BEST/main/whitelist_configs_combined.json
```

Выберите профиль и включите подключение. При запросе iOS разрешите VPN.
Проверяйте загрузку сайтов и видео отдельно по Wi-Fi и мобильной сети.
Импорт JSON и значок VPN сами по себе не доказывают доступность серверов.

В исходном снимке 28 записей, включая автоматический профиль и разделитель.
Работа серверов и вариантов «БС» у конкретного оператора не гарантируется.
Сайты проверки IP, включая 2ip.ru, ipinfo.io и ifconfig.me, направлены напрямую
правилами каталога: прежний IP на них не доказывает неисправность VPN.

## Независимость и безопасность

Репозиторий не обращается к kenkaral45 для обновлений. Сохранён снимок конфигураций,
но серверы и ключи в нём принадлежат сторонним операторам и могут перестать работать.
Это не собственная VPN-инфраструктура и не подтверждение прав на чужие серверы.
Используйте только доступ, на который у вас есть разрешение.

Каталог открыт всем. НЕ добавляйте сюда личные ключи или платные приватные подписки.
GitHub Secret скрывает URL источника, но НЕ содержимое опубликованного JSON:
сгенерированные ключи будут доступны публично и сохранятся в истории Git.

## Обновление

По умолчанию используется статический снимок. Workflow проверяет каталог при push
и pull request. По часовому расписанию обновление пропускается, пока владелец
не настроит оба параметра:

1. Settings → Secrets and variables → Actions → Secret `SUBSCRIPTION_URL`:
   свой разрешённый HTTPS-источник с JSON-конфигурациями Xray.
2. Actions → Variable `ENABLE_SUBSCRIPTION_REFRESH` = `true`:
   подтверждение, что полученные конфигурации разрешено публиковать открыто.

После настройки можно запустить Actions → Subscription → Run workflow.
Формат источника: непустой JSON-массив объектов с remarks, outbounds и routing
либо HTML с такими JSON-объектами. Обычные списки vless:// и Base64 не поддерживаются.
Workflow не тестирует соединения с VPN-серверами; проверки структурные.

Локальная проверка без сети:

```sh
python3 -m unittest discover -s tests -v
SUBSCRIPTION_SOURCE_FILE=whitelist_configs_combined.json python3 scripts/refresh_subscription.py
```

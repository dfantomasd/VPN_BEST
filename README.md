# VPN_BEST

Независимый каталог подписок для Happ и Karing. Для использования не требуется
запускать Python или держать компьютер включённым.

## Happ на iPhone

Скопируйте ссылку целиком, откройте Happ → «+» → импорт из буфера обмена:

```text
https://raw.githubusercontent.com/dfantomasd/VPN_BEST/main/subscription.txt
```

Подписка содержит ссылки VLESS/Hysteria2 и `happ://routing/onadd/...`:
профиль **Russia** передаётся вместе с подпиской с командой автоматической активации.
После импорта проверьте в Happ наличие активного Russia, дождитесь загрузки GeoIP/GeoSite
и переподключитесь. При первом запросе iOS разрешите VPN.

## Karing на iPhone

Добавить конфигурацию → по ссылке:

```text
https://raw.githubusercontent.com/dfantomasd/VPN_BEST/main/subscription_karing.txt
```

Это **Clash YAML**, несмотря на расширение `.txt`: в отличие от списка VLESS,
он содержит правила маршрутизации, а не только серверы.

ВАЖНО: Karing не позволяет принудительно переключить все локальные настройки
одной подпиской. При добавлении включите **«Сохранить правила перенаправления
провайдера» / Keep ISP diversion rules**. В разделе правил выключите
**«Отключить правила перенаправления [ISP]» / Disable ISP diversion rules**.
Названия могут отличаться между версиями. Выберите режим **Правила / Rule**,
не Global, и сервер в группе VPN_BEST. После изменения переподключитесь.
Для уже импортированной подписки с потерянными правилами добавьте её заново,
включив сохранение правил.

Karing управляет DNS внутри приложения: секция DNS из Clash-подписки не применяется.
Для direct используйте доступный локальный DNS, для proxy — DNS через туннель;
обновите приложение, если отдельных настроек DNS/правил нет.

## Маршрутизация Russia

- Прямой маршрут: `.ru`, `.su`, `.рф`, список `category-ru`, дополнительные
  российские банковские/государственные домены, российские IP и локальные сети.
- По умолчанию весь остальной трафик идёт через выбранный VPN-сервер.
- Отдельный список «только заблокированных зарубежных сайтов» не используется:
  иначе нельзя надёжно определить, какой новый зарубежный сервис требует VPN.
- Зарубежные проверки IP (`ipinfo.io`, `ifconfig.me`, `browserleaks.com` и другие)
  больше не имеют старого принудительного direct-исключения. `2ip.ru` остаётся direct
  как российский домен. Встроенный iCloud Private Relay может менять результат проверки.
- Название **Russia** относится к правилам обхода, а не к стране VPN-сервера.

Полного и вечного списка всех банков, порталов и их CDN не существует: геобазы
могут ошибаться, новые домены могут отсутствовать. Если конкретный сервис не работает,
нужны домен и журнал маршрутизации для добавления точного исключения.
При полном отсутствии связи правила не восстанавливают доступ оператора.

## Без российских VPN-серверов

Из **обеих новых подписок** исключаются узлы с названием Россия/Russia/🇷🇺,
а также входные IP, попадающие в российские диапазоны GeoIP или имеющие
российскую регистрацию сети в RDAP (RIPE/региональные реестры).
Для доменных имён сохраняются результаты DNS-проверки; неразрешимые имена
исключаются, а не считаются зарубежными. GeoIP определяет входной адрес,
но не доказывает фактическую страну выхода или владельца инфраструктуры.
При изменении DNS/геобазы нужна пересборка.

На момент сборки: **по 20 узлов в Happ и Karing**. XHTTP-узлы требуют актуальной
версии Karing и проверки на устройстве; TCP-узлы помещены первыми в списке выбора.
При будущих обновлениях неподдерживаемые расширенные XHTTP-параметры могут приводить
к исключению узла из Karing с записью причины в отчёт, а не к тихой потере настроек.

Полный отчёт исключений: [build_report.json](build_report.json).
Старый `whitelist_configs_combined.json` — исходный снимок, НЕ новая подписка:
в нём оставлены оригинальные записи, включая российские; не импортируйте его
для этих требований. Экспорт раскрывает балансировщики в отдельные узлы,
не переносит их алгоритм автоматического выбора, QUIC-блокировку и direct для BitTorrent.

## Независимость и безопасность

Репозиторий не обращается к kenkaral45 для обновлений. Сохранён снимок конфигураций,
но серверы и ключи в нём принадлежат сторонним операторам и могут перестать работать.
Это не собственная VPN-инфраструктура и не подтверждение прав на чужие серверы.
Используйте только доступ, на который у вас есть разрешение.

Каталог открыт всем. НЕ добавляйте сюда личные ключи или платные приватные подписки.
GitHub Secret скрывает URL источника, но НЕ содержимое опубликованного JSON:
сгенерированные ключи будут доступны публично и сохранятся в истории Git.

## Обновление

По умолчанию используется статический снимок. Workflow проверяет каталог при push
и pull request. По часовому расписанию обновление пропускается, пока владелец
не настроит оба параметра:

1. Settings → Secrets and variables → Actions → Secret `SUBSCRIPTION_URL`:
   свой разрешённый HTTPS-источник с JSON-конфигурациями Xray.
2. Actions → Variable `ENABLE_SUBSCRIPTION_REFRESH` = `true`:
   подтверждение, что полученные конфигурации разрешено публиковать открыто.

После настройки можно запустить Actions → Subscription → Run workflow.
Формат источника: непустой JSON-массив объектов с remarks, outbounds и routing
либо HTML с такими JSON-объектами. Обычные списки vless:// и Base64 не поддерживаются.
Workflow не тестирует соединения с VPN-серверами; проверки структурные.
После обновления исходного каталога workflow пересобирает обе подписки,
обновляет публичные геоданные и повторяет фильтрацию российских входных узлов.
Пока автообновление источника отключено, геоданные Karing остаются снимком.
Happ получает геофайлы по ссылкам профиля из Loyalsoldier.

Локальная проверка без сети:

```sh
python3 -m unittest discover -s tests -v
SUBSCRIPTION_SOURCE_FILE=whitelist_configs_combined.json python3 scripts/refresh_subscription.py
python3 scripts/build_clients.py
python3 scripts/build_clients.py --check
```

Обновить геоданные и DNS-снимок (требуется интернет):

```sh
python3 scripts/build_clients.py --refresh-rules
```

## Проверка на телефоне

1. Импортируйте соответствующую новую ссылку и проверьте активность правил.
2. Проверьте Сбер/Т-Банк/Госуслуги: в журнале соединений ожидается DIRECT.
3. Проверьте YouTube и зарубежный сайт IP: ожидается VPN/выбранный сервер.
4. Повторите на Wi-Fi и мобильной сети. Один значок VPN не доказывает работу.

Локально проходят 19 тестов, проверка YAML и проверка конфигурации Mihomo `-t`.
Это НЕ проверка импорта в iOS Happ/Karing и НЕ тест доступности VPN-серверов.

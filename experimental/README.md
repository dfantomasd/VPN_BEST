# Экспериментальные подписки

Основные подписки не изменяются. Тестовые ссылки:

- Karing: https://raw.githubusercontent.com/dfantomasd/VPN_BEST/main/subscription_test_karing.txt
- Happ: https://raw.githubusercontent.com/dfantomasd/VPN_BEST/main/subscription_test_happ.txt

Это отдельный профиль для проверки Telegram и Instagram. Весь трафик направляется через выбранный прокси, без DIRECT-исключений для российских сайтов. Имена содержат источник и стабильный идентификатор. География входов не фильтруется: мобильные whitelist-источники могут содержать российские входные узлы.

Источники перечислены в `sources.json`; новые добавляются туда. Выбраны публичные списки igareck (основной, мобильный, whitelist), kort0881 (агрегация) и V2RayAggregator. Это кандидаты по актуальности и назначению, а не гарантия качества. Исходный код сторонних сборщиков не запускается.

Консервативный импорт: только VLESS TCP с TLS/Reality. Неизвестные параметры и другие транспорты пропускаются, чтобы не потерять настройки при преобразовании. Не более 25 новых узлов с каждого источника; дубликаты объединяются.

Проверки через отдельный локальный Xray для каждого узла:

1. HTTPS telegram.org (отдельный диагностический результат).
2. Настоящий MTProto req_pq_multi к пяти адресам DC Telegram, проверка resPQ и nonce.
3. HTTPS www.instagram.com с проверкой сертификата, без аккаунта.

В экспорт проходят только узлы, дважды прошедшие пункты 2 и 3, с каждым обменом Telegram не дольше 1500 мс и полной загрузкой 1 МиБ с speed.cloudflare.com не медленнее 5 Мбит/с. Профили отсортированы по меньшей скорости из двух замеров; это внешняя скорость, не прогноз для LTE. Дополнительно проверяются одиночные профили текущего основного каталога без изменения основной подписки. HTTP 200/301/302 не доказывает работу аккаунта, ленты, Reels или Direct; MTProto handshake не доказывает доступ ко всем DC, медиа и звонкам. Проверки выполняются на машине запуска, результаты с телефона/оператора могут отличаться. Результаты и время — `report.json`.

Отдельный workflow запускается по запросу и каждые шесть часов (GitHub может задерживать). При отсутствии прошедших узлов публикация прекращается, старые ссылки сохраняются; проверяйте дату отчёта и статус Actions. Для ручного запуска: `python scripts/experimental.py --xray /path/to/xray`.

Исправление экспорта Happ: профили включают локальный SOCKS-вход 127.0.0.1:10808 и DNS, ранее SOCKS добавлялся только локальным тестом. Старый результат не подтверждал полноту экспортированного профиля.
